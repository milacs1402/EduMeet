# EduMeet 📚

Projeto pessoal desenvolvido para estudar **React** e **API REST** na prática.

## Sobre

Sistema de cadastro e gerenciamento de alunos. O objetivo do projeto não é ser uma aplicação completa, mas sim um ambiente de aprendizado para explorar a comunicação entre frontend e backend.

## Tecnologias

**Frontend**
- React
- CSS (Grid, Flexbox, responsividade)

**Backend**
- Node.js
- Express

**Banco de Dados**
- MySQL (hospedado na KingHost)

## O que aprendi

- Criar uma API REST do zero com Node.js + Express
- Conectar o React ao backend com `fetch`
- Operações CRUD completas (Create, Read, Update, Delete)
- Uso de variáveis de ambiente com `dotenv`
- Validação de dados no frontend e no backend
- Responsividade com CSS Grid e media queries

## Funcionalidades

- [x] Cadastro de alunos
- [x] Validação de campos obrigatórios
- [x] Validação de RA e RG duplicados
- [x] Busca de alunos por nome ou RA
- [x] Editar cadastro
- [X] Excluir cadastro
